# OKF-Schema Requirements

This is a real-life use of the okfreq requirements layer for the `okf-schema` itself.

It is organized in several `tiers`, following the default settings done by `okfreq init`.

| Tier | Description | Usage |
| --- | --- | --- |
| [StRS](tiers/strs/index.md) | Stakeholder Requirements Specifications | Complex use case, user journey |
| [SwRS](tiers/swrs/index.md) | Software Requirements Specifications | Testable transitions |
